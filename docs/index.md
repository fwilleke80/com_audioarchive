# Punga Audio Archive documentation

The documentation is divided by audience.

## User guide

The [User guide](user/index.md) is for Joomla administrators, site owners, and editors. It explains installation, configuration, everyday clip management, frontend menu items, analyses, maintenance, backup, and troubleshooting.

## Developer documentation

The [Developer documentation](developer/index.md) is for maintainers and extension developers. It describes architecture, package structure, database tables, protected storage, routing, the unified player, analysis jobs, frontend state, analytics events, template overrides, builds, and testing.
