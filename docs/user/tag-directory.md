# Tag Directory

Create a menu item of type **Punga Audio Archive → Tag Directory**.

The Tag Directory can:

- Display optional introductory text
- Show all accessible Audio Archive tags or a selected subset
- Link to an automatically resolved or explicitly selected Archive menu item
- Hide tags without accessible clips
- Order by title, clip count, or backend selection order
- Use cards, list, or compact presentation
- Show or hide descriptions and accessible clip counts

Counts respect publication, category, clip access, component-wide frontend access, and restrictions on the target Archive menu item.

Tags across the component link back to an appropriate filtered Archive. When a Joomla tag has a description, it is also exposed through the link's standard browser tooltip.
