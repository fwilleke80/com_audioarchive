# Clip Detail pages

Clip Detail pages present the selected clip and its configured public metadata.

## Main content

Depending on global and Archive menu-item options, a page can show:

- Unified player in the selected presentation
- Description
- Category and tags
- Duration and dates
- Original filename, format, codec, and file size
- Play and download counts
- Like/Dislike controls
- Share, Sound Board, playlist, edit, and download actions
- Joomla Custom Fields

Protected playback, analyses, and downloads enforce clip, category, publication, and access rules.

## Previous and Next

Optional Previous and Next links follow the active Archive menu item's filters, restrictions, sorting, and access rules.

## Related Clips

Related Clips appear after the main information and before Previous/Next navigation. The section is hidden when no eligible candidates exist.

Candidates must share Joomla tags with the current clip. Available ranking modes are:

- Prefer distinctive shared tags
- Most shared tags first
- Same category first

The result count, minimum shared tags, ranking, columns, and Share/Add actions are configurable globally and per Archive menu item.

Related Clips use the Archive-style responsive table/cards, inherit Archive list colours, and render the unified Minimal player.

## Return context

When a visitor opens a detail page from an Archive or Sound Board, the exact same-origin origin URL can be retained in the current browser tab for 24 hours. The return link then restores the previous page state while the clip keeps a clean canonical URL.
