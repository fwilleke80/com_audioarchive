# Player usability — 0.13.7

Frequency Profile now shows a dB relative axis, a peak marker and sample inspection. Hover or touch the graph, or focus it and use Left/Right, Home and End. Values are relative to the profile peak, not calibrated sound pressure levels. Existing profile files need no regeneration.

Share → Copy link opens a small dialog. Start at is unchecked each time; checking it uses the position captured when the dialog opened. At zero it is disabled. The URL can also be selected and copied manually.

Authorised previews display Unpublished, Scheduled or Expired notices. This does not broaden access or archive visibility.

Validation: focused JavaScript renderer and sharing tests, syntax and XML/JSON checks, package validation. PHP lint and live Joomla/browser validation were unavailable in this environment.
