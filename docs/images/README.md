# Documentation images

Store real screenshots and diagrams for the user and developer guides in this directory.

Recommended conventions:

- Use descriptive lowercase filenames, for example `archive-filter.webp` or `analysis-queue.webp`.
- Prefer WebP or optimised PNG.
- Crop screenshots to the relevant interface area.
- Remove private site data before committing images.
- Add a short alt text wherever an image is referenced.
- Avoid screenshots for values or wording that are likely to change frequently.

No placeholder screenshots are included in the source archive.
